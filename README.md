# Katana Connector

Нативное iOS-приложение-компаньон для Katana PWA. Открывается на Dashboard, с которого запускаются функции устройства. Продукт, архитектура и план — в [`docs/`](docs/), правила работы — в [`CLAUDE.md`](CLAUDE.md).

> Раньше приложение называлось **ScreenshotSweep** (Bundle ID `local.sweep.ScreenshotSweep`). У Katana Connector новый Bundle ID `app.katana.connector`, поэтому iOS установит его **как отдельное приложение** рядом со старым ScreenshotSweep. Старое приложение можно удалить вручную; данные между ними не переносятся.

Сейчас на Dashboard: состояние подключения (Katana пока не подключена — подключение появится в следующих версиях) и первая функция — **Screenshot Cleanup**.

## Screenshot Cleanup

Разбор скриншотов: показать скриншот → «оставить» или «на удаление» → проверить список → подтвердить удаление.

- Доступ к фото запрашивается только кнопкой «Разрешить доступ к фото» внутри «Разобрать скриншоты», не при запуске приложения и не при открытии по ссылке.
- Katana может открыть экран ссылкой `katana-connector://open?v=1&feature=screenshot_cleanup` (или `feature=pairing`); ссылка только открывает экран.
- Без сети, аналитики, сторонних SDK и секретов. Фото не покидают устройство.
- Медиатека не меняется, пока вы не нажмёте «Удалить» на экране проверки и не подтвердите (iOS дополнительно покажет системный диалог).
- Удаление — одна транзакция `PHPhotoLibrary.performChanges`; файлы попадают в «Недавно удалённые».
- Размер освобождаемого места не показывается: без загрузки оригиналов из iCloud его нельзя получить честно, поэтому показывается только количество.

### Управление

- Свайп вправо / «Оставить», свайп влево / «На удаление».
- «Главная» (слева вверху) — возврат на Dashboard.
- «Отменить» (слева вверху, рядом с «Главная») — откат последнего решения, можно несколько раз.
- Каждые 30 скриншотов открывается экран проверки; там тап по скриншоту убирает его из кандидатов.

## Сборка (без локального Xcode)

1. Запушьте изменения в GitHub (`lovejoy-goose/ScreenshotSweep`).
2. GitHub → Actions → **Build iOS (unsigned)** запускается на push в `main`, на pull request или вручную (Run workflow / `gh workflow run build-ios.yml --ref <ветка>`).
3. Когда сборка зелёная, откройте run → Artifacts → скачайте `katana-connector-unsigned-ipa` (zip) и распакуйте — внутри `KatanaConnector.ipa`.

Workflow: `xcodegen generate` → `xcodebuild -scheme KatanaConnector -sdk iphoneos CODE_SIGNING_ALLOWED=NO` → `Payload/KatanaConnector.app` → `KatanaConnector.ipa`.

## Установка через Sideloadly

1. Установите [Sideloadly](https://sideloadly.io) (и iTunes/iCloud с сайта Apple на Windows).
2. Подключите iPhone кабелем, нажмите «Доверять этому компьютеру».
3. Перетащите `KatanaConnector.ipa` в Sideloadly, введите свой Apple ID (сам Sideloadly подписывает приложение; пароль вводится только в нём), нажмите **Start**.
4. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять».
5. iOS 16+: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить, перезагрузить.
6. С бесплатным Apple ID подпись живёт 7 дней — потом переустановите через Sideloadly.

## Проверка сборки

1. Установить .ipa — на экране появится «Katana Connector» (отдельно от старого ScreenshotSweep).
2. Открыть приложение — Dashboard, **никаких запросов разрешений**.
3. Нажать «Разобрать скриншоты» → «Разрешить доступ к фото» — только теперь iOS спрашивает доступ к фото. Разрешить («Все фото»; при «Выбранные» появится баннер ограниченного доступа).
4. Увидеть свои скриншоты (от старых к новым), разобрать 10 штук.
5. Нажать «Проверить (N)» и посмотреть кандидатов.
6. Оставить в кандидатах один тестовый скриншот и удалить его.
7. Найти его в Фото → Альбомы → «Недавно удалённые».
8. «Главная» возвращает на Dashboard; при повторном входе прогресс разбора сохраняется (до перезапуска приложения).

Полный ручной чек-лист — в [`docs/TESTING.md`](docs/TESTING.md).
