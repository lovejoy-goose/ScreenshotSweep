# ScreenshotSweep

Минимальное SwiftUI-приложение для разбора скриншотов: показать скриншот → «оставить» или «на удаление» → проверить список → подтвердить удаление.

- Без сети, аналитики, сторонних SDK и секретов.
- Медиатека не меняется, пока вы не нажмёте «Удалить» на экране проверки и не подтвердите (iOS дополнительно покажет системный диалог).
- Удаление — одна транзакция `PHPhotoLibrary.performChanges`; файлы попадают в «Недавно удалённые».
- Размер освобождаемого места не показывается: без загрузки оригиналов из iCloud его нельзя получить честно, поэтому показывается только количество.

## Управление

- Свайп вправо / «Оставить», свайп влево / «На удаление».
- «Отменить» (слева вверху) — откат последнего решения, можно несколько раз.
- Каждые 30 скриншотов открывается экран проверки; там тап по скриншоту убирает его из кандидатов.

## Сборка (без локального Xcode)

1. Создайте репозиторий на GitHub и запушьте проект:
   ```bash
   git init && git add . && git commit -m "ScreenshotSweep MVP"
   ```
   ```bash
   git remote add origin git@github.com:<you>/ScreenshotSweep.git && git push -u origin main
   ```
2. GitHub → Actions → **Build iOS (unsigned)** запустится сам (или Run workflow вручную).
3. Когда сборка зелёная, откройте run → Artifacts → скачайте `ScreenshotSweep-unsigned-ipa` (zip) и распакуйте — внутри `ScreenshotSweep.ipa`.

Workflow: `xcodegen generate` → `xcodebuild -sdk iphoneos CODE_SIGNING_ALLOWED=NO` → `Payload/ScreenshotSweep.app` → `ScreenshotSweep.ipa`.

## Установка через Sideloadly

1. Установите [Sideloadly](https://sideloadly.io) (и iTunes/iCloud с сайта Apple на Windows).
2. Подключите iPhone кабелем, нажмите «Доверять этому компьютеру».
3. Перетащите `ScreenshotSweep.ipa` в Sideloadly, введите свой Apple ID (сам Sideloadly подписывает приложение; пароль вводится только в нём), нажмите **Start**.
4. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять».
5. iOS 16+: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить, перезагрузить.
6. С бесплатным Apple ID подпись живёт 7 дней — потом переустановите через Sideloadly.

## Проверка первой сборки

1. Установить .ipa.
2. Разрешить доступ к фото («Все фото»; при «Выбранные» появится баннер ограниченного доступа).
3. Увидеть свои скриншоты (от старых к новым).
4. Разобрать 10 штук.
5. Нажать «Проверить (N)» и посмотреть кандидатов.
6. Оставить в кандидатах один тестовый скриншот и удалить его.
7. Найти его в Фото → Альбомы → «Недавно удалённые».
